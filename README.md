# Ranking video maker checklist

A short checklist for building a Top-5 countdown Short from your own clips. Maintained alongside [ShortsRank](https://shortsrank.com/), a free [ranking video maker](https://shortsrank.com/ranking-video-maker/) for vertical Shorts and Reels.

> TL;DR: pick a ranked list, normalize clip length and framing, write one on-screen claim per rank, then stitch in reverse order so #1 lands last.

## 1. Decide the list before you open the editor

- Write the five ranks on paper first (worst → best, or #5 → #1).
- Each rank needs one clear claim viewers can read in under two seconds.
- Prefer clips you already own. Re-encoding someone else's vertical video rarely looks as clean.

## 2. Normalize clips

- Same resolution, frame rate, and aspect (usually 9:16).
- Trim dead air at the start of every clip; the hook is the first half-second of each rank.
- Keep clip lengths close so the countdown feels even.

## 3. Build the countdown

1. Open the [ranking video maker](https://shortsrank.com/ranking-video-maker/).
2. Drop clips in reverse order (#5 first, #1 last) so retention lands on the reveal.
3. Add the on-screen rank label and a short claim for each slot.
4. Export vertical and check the first three seconds on mute.
